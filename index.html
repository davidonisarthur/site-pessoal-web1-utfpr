Projetos e interesses

Meu primeiro site pessoal

Projeto acadêmico iniciado com HTML para organizar o conteúdo com títulos, parágrafos, listas, imagens, links e um formulário.

Nesta segunda etapa, um arquivo CSS externo define a apresentação visual. A página mantém a navegação por seções e não utiliza frameworks ou JavaScript.

Abrir a página do projeto

Temas desta etapa de aprendizado

  • Estrutura básica de documentos HTML.
  • Organização semântica e acessibilidade do conteúdo.
  • Publicação de páginas estáticas no GitHub Pages.

Habilidades e tecnologias

Conteúdos praticados neste projeto:

  • HTML: estrutura do documento, títulos e parágrafos.
  • CSS: cores, tipografia, espaçamentos e organização responsiva.
  • Navegação: hyperlinks e âncoras para as seções.
  • Imagens: uso de arquivo local com texto alternativo.
  • Formulários: campos com rótulos e tipos de entrada apropriados.
